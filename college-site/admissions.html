Admissions

How to apply

Applications open each spring for Class VIII entry and each summer for 1st Year. All candidates sit a written entry test; shortlisted candidates are then called for an interview.

Application steps

1. Check Eligibility

Age and academic requirements for each entry point.

2. Submit Application

Download and complete the admission form, then submit with required documents.

3. Entry Test / Interview

Shortlisted candidates are called for a test and/or interview.
